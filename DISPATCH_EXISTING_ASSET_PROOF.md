## Implementation decisions made during the build (per mission: define, don't stop)

- **Trip Card `required` flag.** Arrival, Pickup, BOL, Load Check, Delivery, and POD are required-complete before Close Load. Delay is intentionally **not required** — it's an exception record, not a milestone every load produces; a load with no delay should not be blocked by an empty Delay box. `close_load()` still surfaces Delay in the "open items" list for visibility, it just doesn't gate.
- **HOLD applies to sandbox runner-ups only**, not to the committed load. The clock starts at the moment Mike commits a sibling entry (the moment an entry becomes a "loser"), not at load-evaluation time.
- **Mike-override on Close Load** is logged on the Trip Card itself (who/when/which items were still open), not silently allowed — Mike retains authority, but the override is auditable.
- **Onboarding Packet bundling rule**: any Communication Card of type `ONBOARDING_PACKET`, regardless of which single document was requested, attaches the full standard set. This is implemented as a fixed rule in `library.py`, not a per-request choice.
- **Accounting and Outlook are mocked, not stubbed-out.** Both adapters produce a real receipt object with a `mocked=True` flag and a reference id, so downstream code (and tests) can assert a handoff actually happened, without requiring live external systems.
